## 描述

DeepSeek Harness Git 插件 —— 会话 Tab 栏中添加 Git 管理面板，变更、提交、历史、分支、远端同步、合并冲突一站完成，Message 可 AI 生成。

## 功能介绍

- **工作区感知：** 跟随当前会话定位仓库
- **变更与 Diff：** 文件夹树、暂存状态、单文件 Diff
- **提交历史：** 浏览提交，查看当次 Diff
- **提交：** 一键提交全部变更，或在工具栏菜单里只提交暂存区；Message 由 AI 生成（模型与提示词可按工作区配置）
- **分支：** 切换、新建、删除（标注风险）、合并
- **远端：** Fetch、Pull、Push、Publish，一键同步（先拉后推），拉取走合并而不是变基
- **合并冲突：** 拉取或分支合并产生的冲突保留在工作区，在 Diff 面板里逐块解决（也可整侧采用），再按文件或一次性全部标记为已解决

## 安装教程

使用 DSH 的新增插件功能，输入包名：dsh-cool-git 即可。
