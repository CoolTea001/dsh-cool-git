## 描述

DeepSeek Harness Git 插件 —— 在会话视图里提供 Git 页，用于查看 diff 与执行 Git 操作。

## 功能介绍

- **会话 Tab 栏新增 Git 页** —— 在 对话 / 轨迹 / 终端 之后多一页，切换方式完全一致。
- **一条工具栏，按使用顺序排列** —— 左栏首行依次是工作区名称、当前分支，以及「同步变更」和刷新两个按钮；同步变更按钮文字只出现在悬停提示里，按钮内部是上下两个箭头和各自的提交数（`↓` 落后、`↑` 领先，为 0 也显示，没有上游时不显示数字）。下面是 变更文件区、提交历史，右侧 Diff 查看区占满其余会话区域。
- **切换分支** —— 点击首行的分支名打开本地分支列表（按提交时间倒序、当前分支带勾选）并直接切换。切换会改动工作区，因此页面会重新读取仓库，并放弃原来显示的 Diff。
- **同步变更** —— 一个按钮完成整轮同步：先把当前分支从上游快进，再推送剩下的提交。先拉取是推送不会因为落后而被拒绝的原因；历史已经分叉时直接拒绝而不是合并，所以这个按钮不会凭空造出合并提交，也不会把工作区留在冲突状态，拉取被拒时整轮同步就此停止。没有上游时没有可快进的东西，直接推送到唯一的远程仓库（并把它设为上游）；没有远程或存在多个远程时会说明情况，而不是猜一个。
- **错误统一用对话框** —— 所有失败都弹同一个对话框：切换分支被拒、拉取或推送被远程拒绝、Host 无法回答的读取。目录不是 Git 仓库不算失败，这种情况仍由面板就地说明。操作成功不弹提示，重新读取后的页面本身就是结果。
- **变更文件** —— 列出 `git status` 报告的全部路径（已暂存、未暂存、未跟踪、重命名、删除、冲突），并保留每一行在索引与工作区的状态。
- **Diff 查看** —— 点击文件查看它相对 `HEAD` 的改动（未跟踪文件与 `/dev/null` 比较）；点击提交查看整次提交的完整补丁，按文件分区，带双侧行号与每文件 `+N −M` 统计。
- **提交历史** —— 最近提交及其作者、时间、分支/标签装饰；合并提交与第一个父提交比较。
- **复制** —— Diff 头部的按钮复制的就是屏幕上这段补丁。
- **主题自动适配** —— 基于 DSH 主题变量渲染，兼容大多数主题插件，明暗两种外观都正常。

## 安装教程

使用 DSH 的新增插件功能，输入包名：dsh-cool-git 即可。

安装或更新后请重载 / 重启 DSH：浏览器端刷新页面即可生效，但 Host 端的路由是在插件挂载时注册的。

## 目前存在的几个限制

- 暂存、提交、新建与删除分支都还没有；页面能改动的只有两件事：切换分支、同步变更（先快进式拉取，再推送）。
- 同步里的拉取只做快进：两边已经分叉时页面会说明原因并停止，不会继续推送；合并或变基请自行处理。
- 页面不会弹出凭据输入（`GIT_TERMINAL_PROMPT=0`），所以本机没有现成凭据的远程会直接报认证失败。
- 领先/落后计数来自 `git status`，其新鲜度取决于上一次 fetch：别的机器推上来的提交，在下一次同步之前是看不见的。
- 所有写操作都需要会话自身的写权限：在只读模式下分支不会变，页面会说明原因。
- 左侧分栏高度固定，暂不支持拖拽调整。
- 提交历史最多 60 条，超过 4 MiB 的补丁会被标记为已截断。

## 参与贡献

欢迎提交 Issue 和 PR。

```
// 克隆项目
git clone https://github.com/CoolTea001/dsh-cool-git.git

// 安装依赖
cd dsh-cool-git
pnpm install

// 启动本地开发
pnpm run dev

// 本地安装：使用 DSH 的新增插件功能，输入本地项目路径即可

// 重启 DSH 服务
dsh web
```
